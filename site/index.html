Watch the whole yard at once.

Yard Pulse is a Power Apps code component (PCF). Point it at any Dataverse view of yard slots and it draws every block as a live heatmap. Slots that change pulse, units over the dwell limit get a red ring, and a double-click opens the record.

    How it fits together

    Dataverse view→ dataset + property-sets→ readSlots()→ buildYard()→ YardView

    The model and the view have no PCF dependency. That lets this page run them without Dataverse, lets the tests check them in Node, and leaves index.ts as a thin adapter.

    1 · Import

    Download the managed solution from the latest release and import it:

    pac auth create --environment https://yourorg.crm4.dynamics.com
pac solution import --path YardPulse_managed.zip

    2 · Map your columns

    Add the control to any subgrid or view. Bind Block, Row, Bay and Status, plus Dwell and Unit if you have them. Text, choice and lookup columns all work.

    Status labels it understands:
Free · Empty · Vrij       → free
Reserved · Booked · Gepland → reserved
Blocked · Hold · Defect   → blocked
anything else             → occupied

    3 · Build it yourself

    Every step runs locally and in CI. No environment needed until you deploy:

    npm ci && npm test
npm run build            # pcf-scripts
npm run demo             # this page
dotnet build solution -c Release
